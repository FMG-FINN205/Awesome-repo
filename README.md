## 📖 Giới Thiệu

> *"Một lập trình viên giỏi không chỉ biết viết code tốt, mà còn biết tận dụng sức mạnh của cộng đồng mã nguồn mở."*

**Awesome Repos** là kho lưu trữ cá nhân được lập ra nhằm mục đích phân loại, lưu trữ và tổng hợp những repository chất lượng cao trên GitHub. Dự án đóng vai trò như một **bản đồ tri thức (Knowledge Map)** giúp:

- 🔍 **Tiết kiệm thời gian tìm kiếm**: Thay vì phải đào bới hàng giờ trên GitHub, bạn có thể tra cứu nhanh các công cụ đã được chọn lọc và kiểm chứng.
- 💡 **Mở rộng góc nhìn công nghệ**: Khám phá các thư viện đột phá, phong cách thiết kế kiến trúc chuẩn mực và xu hướng mới nhất trong ngành phần mềm.
- 🛠️ **Thực chiến hóa dự án**: Ứng dụng ngay các boilerplate, component UI, framework tối ưu vào các sản phẩm thực tế.

## 🎯 Tiêu Chí Tuyển Chọn

Mỗi repository được đưa vào danh sách này đều hướng tới các tiêu chuẩn sau:

| Tiêu chuẩn | Mô tả chi tiết |
| :--- | :--- |
| **⭐ Đột phá & Hữu ích** | Giải quyết bài toán thực tế xuất sắc, có tài liệu (docs) rõ ràng và cộng đồng hoạt động tích cực. |
| **⚡ Tối ưu hiệu năng** | Ưu tiên các giải pháp thế hệ mới (Rust/Go tooling, Modern Web stack, High throughput AI). |
| **🎨 Trải nghiệm tốt** | Giao diện đẹp, DX (Developer Experience) mượt mà, dễ cài đặt và tích hợp. |
| **🔄 Cập nhật liên tục** | Dự án được duy trì ổn định, ít tồn đọng lỗi nghiêm trọng và tương thích với công nghệ mới. |

## 📝 Hướng Dẫn & Mẫu Thêm Repo

Khi bạn phát hiện một repository hay, bạn có thể bổ sung theo 2 định dạng chuẩn bên dưới:

### 🔹 Định dạng 1: Danh sách chi tiết (Khuyên dùng)
```markdown
- **[Tên Repo](https://github.com/tác-giả/tên-repo)**: Tóm tắt 1-2 câu ngắn gọn về tính năng chính và lý do nên dùng.
  - 🏷️ **Tags**: `Tag1`, `Tag2`, `Ngôn-ngữ`
  - ⭐ **Đặc điểm nổi bật**: Tính năng giải quyết vấn đề cốt lõi.
  - 🔗 **Liên kết**: [Trang chủ / Tài liệu](https://example.com)
```

### 🔹 Định dạng 2: Dạng bảng cô đọng
```markdown
| Repository | Mô tả ngắn gọn | Công nghệ / Tags | Stars |
| :--- | :--- | :--- | :--- |
| **[tên-repo](https://github.com/...)** | Mô tả giải pháp | `Ngôn ngữ`, `Chủ đề` | [![Stars](https://img.shields.io/github/stars/owner/repo?style=social)](https://github.com/owner/repo) |
```
